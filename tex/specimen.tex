\lbl{Text, 11 on 12 pt}
A function $f(x)$ is said to be a prime-representing function if $f(x)$ is
a prime number for all positive integral values of~$x$. It will be shown that
there exists a real number $A$ such that $[A^{3^x}]$ is a prime-representing
function, where $[R]$ denotes the greatest integer less than or equal to~$R$.
{\small\par\smallskip \textit{Footnotes and references are set in the 9 pt cut:}
Ingham, \textit{On the difference between consecutive primes}, Quart.\ J.\
Math.\ Oxford Ser.\ vol.\ 8 (1937) pp.~255--266.\par}
